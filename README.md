Uma landing page elegante e responsiva para apresentação de serviços de beleza e extensões de cílios.

## ✨ Visão geral
Este projeto foi desenvolvido para destacar os principais serviços do estúdio, apresentar os benefícios das extensões de cílios, exibir modelos disponíveis e facilitar o contato direto via WhatsApp.

## 🛠️ Tecnologias
- HTML
- CSS
- Google Fonts

## 📁 Estrutura do projeto
- `index.html` — estrutura principal da página
- `style.css` — estilos e ajustes responsivos
- `global.css` — reset e configurações globais
- `assets/` — imagens e ícones utilizados no layout

## 🎯 Funcionalidades
- banner principal com apelo visual
- seção de benefícios
- cards de mapping
- apresentação de modelos de extensão de cílios
- botões de contato direcionados para WhatsApp
- layout responsivo para mobile

## ▶️ Como visualizar
1. Abra a pasta do projeto no VS Code.
2. Localize o arquivo `index.html`.
3. Use uma extensão como Live Server para visualizar a página no navegador.

## 📌 Objetivo
Criar uma experiência visual refinada e funcional, com foco em identidade da marca, estética e conversão de clientes.
