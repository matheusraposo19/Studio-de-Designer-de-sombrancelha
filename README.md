# Beauty Studio Landing Page
<img width="1200" alt="Preview do projeto" src="./assets/images/preview.png" />

Landing page elegante e responsiva para apresentação de serviços de beleza e extensão de cílios.

## ✨ Visão geral
Este projeto foi desenvolvido para destacar os principais serviços do estúdio, apresentar os benefícios das extensões de cílios, exibir modelos disponíveis e facilitar o contato direto via WhatsApp.

## 🛠️ Tecnologias
- HTML
- CSS
- Google Fonts

## 📁 Estrutura do projeto
- `index.html` — estrutura principal da página
- `style.css` — estilos e ajustes responsivos
- `global.css` — reset e configurações globais
- `assets/images` — imagens utilizadas no layout
- `assets/icons` — ícones e elementos visuais

## 🎯 Funcionalidades
- Banner principal com apelo visual
- Seção de benefícios
- Cards de mapeamento
- Apresentação de modelos de extensão de cílios
- Botões de contato direcionados para WhatsApp
- Layout responsivo para mobile

## ▶️ Como visualizar
1. Abra a pasta do projeto no VS Code.
2. Localize o arquivo `index.html`.
3. Use uma extensão como Live Server para visualizar a página no navegador.

## 📌 Objetivo
Criar uma experiência visual refinada, funcional e alinhada à identidade da marca, com foco em estética e conversão de clientes.

## 🧩 Status
Projeto finalizado em estrutura e visual, com refinamento contínuo para responsividade e experiência do usuário.
